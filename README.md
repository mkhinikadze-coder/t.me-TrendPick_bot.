## ნაბიჯი 1 — ბოტის შექმნა BotFather-ში (Telegram)

1. Telegram-ის საძიებო ველში ჩაწერე `BotFather` და გახსენი ოფიციალური ანგარიში
   (მას აქვს ლურჯი ✅ ნიშანი).
2. დააჭირე **START** (ან დაწერე `/start`).
3. დაწერე `/newbot` და გააგზავნე.
4. ბოტი გკითხავს **სახელს** (Name) — დაწერე რაც გინდა, მაგ. `Market Analyzer`.
5. ბოტი გკითხავს **username**-ს — ეს უნდა იყოს უნიკალური და მთავრდებოდეს
   სიტყვით `bot`, მაგ. `market_analyzer_2026_bot`. თუ დაწერს "already taken",
   სცადე სხვა.
6. BotFather გამოგიგზავნის შეტყობინებას ტოკენით, ასეთი სახის:
   `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   👉 **დააკოპირე და ჩაინსერტე ჩანაწერად** (ნოუთში ან Notes-ში) — ეს არის შენი
   `TELEGRAM_BOT_TOKEN`, დაგჭირდება ნაბიჯ 4-ში.

## ნაბიჯი 2 — Gemini API გასაღების აღება (Google, უფასო)

1. გახსენი https://aistudio.google.com/app/apikey
2. შედი Google/Gmail ანგარიშით (ჩვეულებრივი შესვლა, არავითარი ბარათი).
3. დააჭირე ღილაკს **Create API key** (ან **Get API key** → **Create API key**).
4. აირჩიე "Create API key in new project" (თუ გკითხავს).
5. გამოჩნდება გასაღები, სახის: `AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   👉 დააკოპირე და შეინახე იგივე ნოუთში — ეს არის `GEMINI_API_KEY`.

ეს არის **სრულიად უფასო** გასაღები (დღეში საკმაო რაოდენობის მოთხოვნა შედის
უფასო ლიმიტში ჩვეულებრივი გამოყენებისთვის). ბარათი არ მოგთხოვს.

## ნაბიჯი 3 — GitHub ანგარიშის გახსნა და ფაილების ატვირთვა

### 3ა. თუ არ გაქვს GitHub ანგარიში
1. გადადი https://github.com/signup
2. ჩაწერე email, პაროლი, username → მიჰყევი ეკრანზე მითითებებს (მარტივი
   captcha/კოდი email-ზე) → **Create account**

### 3ბ. ახალი "საცავის" (repository) შექმნა
1. შესვლის შემდეგ გადადი: https://github.com/new
2. **Repository name** ველში ჩაწერე: `telegram-market-bot`
3. დატოვე **Public** მონიშნული (ან აირჩიე Private — ორივე უფასოა)
4. **სხვა არაფერი არ მონიშნო** (არც README, არც .gitignore — ეს უკვე მზად გაქვს)
5. დააჭირე მწვანე ღილაკს **Create repository**

### 3გ. ფაილების ატვირთვა
1. ახალ, ცარიელ გვერდზე დაინახავ ტექსტს "uploading an existing file" —
   დააჭირე მასზე (ეს ლურჯი ბმულია)
2. გახსნილ ფანჯარაში ჩააგდე (drag & drop) ან **choose your files**-ით ატვირთე
   ეს 5 ფაილი (ყველა ერთდროულად):
   - `index.js`
   - `package.json`
   - `.gitignore`
   - `README.md`
   - `.env.example`
3. დაელოდე სანამ ატვირთვის ზოლები 100%-ზე გავა
4. ჩაწერე commit message-ში, მაგ: `Initial commit` (ან დატოვე ცარიელი)
5. დააჭირე მწვანე ღილაკს **Commit changes**

✅ ახლა შენი კოდი GitHub-ზეა. გვერდის ბმული ასეთი სახის იქნება:
`https://github.com/შენი-username/telegram-market-bot`

## ნაბიჯი 4 — Render ანგარიშის გახსნა და დეპლოი

### 4ა. რეგისტრაცია
1. გადადი https://render.com
2. დააჭირე **Get Started** → **Sign up with GitHub** (ყველაზე მარტივი გზა —
   ავტომატურად დაუკავშირდება შენს GitHub-ს)
3. დაადასტურე წვდომა (**Authorize Render**)

### 4ბ. ახალი Web Service-ის შექმნა
1. Render-ის dashboard-ზე დააჭირე ღილაკს **New +** (ზედა მარჯვნივ)
2. აირჩიე **Web Service**
3. სიაში მოძებნე შენი რეპოზიტორია `telegram-market-bot` და დააჭირე **Connect**
4. შეავსე ველები:
   - **Name**: რაც გინდა, მაგ. `market-analyzer-bot`
   - **Region**: აირჩიე შენთან ყველაზე ახლო (მაგ. Frankfurt)
   - **Branch**: `main`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: აუცილებლად აირჩიე **Free**
5. ჩამოაქაჩე ქვემოთ სექციამდე **Environment Variables** და დააჭირე
   **Add Environment Variable** ორჯერ, დაამატე:
   - Key: `TELEGRAM_BOT_TOKEN`   Value: (ნაბიჯი 1-ის ტოკენი)
   - Key: `GEMINI_API_KEY`       Value: (ნაბიჯი 2-ის გასაღები)
6. დააჭირე ყვითელ/მწვანე ღილაკს **Create Web Service** (ან **Deploy Web Service**)
7. დაიწყება ავტომატური აგება — დაელოდე 1-3 წუთი. **Logs** ტაბში საბოლოოდ
   უნდა დაინახო ტექსტი `🤖 Bot started`

⚠️ **თუ Render გთხოვს ბარათს "ვერიფიკაციისთვის":** ზოგჯერ Render თაღლითობის
საწინააღმდეგოდ ითხოვს ბარათს, რომელზეც მხოლოდ დროებით $1 ჩამოაჭერს და
მაშინვე დაგიბრუნებს — ეს **არ არის გადასახადი**, უბრალოდ ვერიფიკაციაა. ამის
შემდეგ Free პლანი კვლავ სრულიად უფასო რჩება. თუ ბარათის მიცემა საერთოდ არ
გინდა, ალტერნატივა შეგვიძლია განვიხილოთ (მაგ. სხვა უფასო ჰოსტინგი).
